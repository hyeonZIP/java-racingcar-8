# 자동차 경주 ver 1.0

## 주요 기능

### 1️⃣ 경주할 자동차 이름 입력 받기

- [x] `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)` 메시지 출력
- [x] 자동차 이름 입력 받기

### 2️⃣ 시도할 횟수 입력 받기

- [x] `시도할 횟수는 몇 회인가요?` 메시지 출력
- [ ] 시도 횟수 입력 받기

### 3️⃣ 게임 초기화

- [ ] 게임 초기화

### 4️⃣ 라운드 진행

- [ ] `실행 결과` 메시지 출력
  ```markdown
  \n
  실행 결과
  ```
- [ ] 랜덤 값 생성
- [ ] 라운드 진행
- [ ] 라운드 진행 결과 반환
- [ ] 라운드 진행 결과 출력
  ```markdown
  {자동차 이름} : {자동차 위치 만큼 '-' 반복 출력}
  {자동차 이름} : {자동차 위치 만큼 '-' 반복 출력}
  {자동차 이름} : {자동차 위치 만큼 '-' 반복 출력}
  ...
  \n
  ```

### 5️⃣ 우승자 출력

- [ ] 우승자 반환
- [ ] 우승자 출력
  ```markdown
  최종 우승자 : {자동차 이름...}
  ```
